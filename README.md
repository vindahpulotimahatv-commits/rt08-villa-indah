# RT 08 / RW 021 Villa Indah Pulo Timaha — Standalone Premium

Versi ini dibuat khusus agar setiap file HTML bisa dibuka langsung tanpa folder CSS/JS terpisah.

Semua stylesheet, JavaScript, dan ilustrasi hero sudah ditanam langsung ke file HTML.

Untuk GitHub Pages:
1. Upload seluruh file HTML ke repository.
2. Pastikan index.html berada di root.
3. Aktifkan Settings > Pages > Deploy from branch > main / root.
